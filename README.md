# Hospital Management System

A console-based Hospital Management System developed using C++ and Microsoft Visual Studio.

## Features

- Admin, Doctor and Receptionist login
- Patient registration
- Edit and delete patient records
- Search patients by ID
- View all patient records
- Add and update patient diagnosis
- Generate patient bills
- Automatic bill calculation
- File handling to save and load patient records

## Technologies Used

- C++
- Microsoft Visual Studio
- Structures
- Functions
- Arrays
- File Handling
- Text File Storage

1. Open the `.sln` file in Microsoft Visual Studio.
2. Build the solution.
3. Run using Ctrl + F5.
4. Select a login role and enter the demonstration credentials.
